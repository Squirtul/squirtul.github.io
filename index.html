Help fill in the map

Supported airfields are based entirely on my own research, documenting controller positions and airfield specifics. If you notice something incorrect or missing, or simply consider yourself knowledgeable about a field which you'd like to add or improve, reach out!

airports.py

Add/update an aerodrome

Airfields are documented with their name and coordinates as shown below.

AIRPORTS = { "EBCI": (50.463007, 4.459511), ... } AIRPORT_NAMES = { "EBCI": "Charleroi", ... }
airport_positions.py

Add/update controller positions

Control positions are categorised into their 5 main types. A position should be added if it would cover the aerodrome top-down when online.

"LZIB": { "DEL": [], "GND": ["LZIB_GND"], "TWR": ["LZIB_TWR"], "APP": ["LZIB_APP"], "ACC": ["LZBB_CTR", ...], },

All positions are checked by hand, so support is needed with filling up the dataset!
